# CalligraGuard

## Current manuscript: source-dependency-balanced adaptation

**CalligraGuard: Source-Dependency-Balanced Adaptation for Glyph Inspection** concerns containment of adaptation-induced collateral alarms through native source dependencies; it is not a neural-architecture claim or a new general robust-estimation theorem.

Start with the [versioned release preparation](releases/source-balanced-20261031/README.md), [scientific summary and claim boundary](docs/CURRENT_MANUSCRIPT_20261031.md), and [asset identities](releases/source-balanced-20261031/ASSET_MANIFEST.json).

## Current scientific result

Under same-panel session qualification, ordinary robust fitting flags 869/1,792 unchanged controls in altered batches, compared with zero for source-balanced fitting. Altered-target detections are 1,790/1,792 versus 1,789/1,792; both flag 8/800 fresh normal sessions. A graph-respecting pool median is an effective tied alternative, not omitted competition.

These controlled alteration cases are development evidence, not thousands of independent natural defects. Other-panel calibration fails (108/800 normal-session flags). Authentic historical checks give a visible-repair tie and a below-tolerance correction, not natural-event superiority. The detector uses 128 fixed probes. Intent labels, timed designer benefit, and universal false-alarm control are not established.

The approved complete package includes editable sources and full numerical records for panel qualification and the final historical study. Do not imply that publishing the compact package distributes every project artifact.
