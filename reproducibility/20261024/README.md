# Verified computational-closeout bundles

These are small, SHA-256-verifiable archives, not pretrained-model distributions. Check `MANIFEST.json` before extracting into a new directory with a current Python/tar implementation.

| Archive | Included material |
|---|---|
| `v3_completed_results.tar.xz` | Exact completed-v3 summary, audit receipt, verified-fit registry and prediction checksum inventory |
| `source_qa_20261024.tar.xz` | Six executed source-QA/reproduction/audit Python files for original Urdu binaries and reconstructed Malayalam masters |
| `official_comparison_source.tar.xz` | Executed official Diffenator3 preparation/runner and independently recounted native output summary |
| `compact_research_evidence.tar.xz` | Compact records for developmental verifier, stress, historical fitting, region/review and source-QA stages |

The frozen v3 scientific source is already in `experiments/v3`; it is not duplicated here. Original fonts and original Glyphs files are never bundled. Required private artifacts must be reacquired at their pinned revisions and hashes. Third-party fonts/tools retain their own licenses.

Executed historical scripts retain their original workspace conventions. Treat them as provenance snapshots; inspect paths and use the portable wrapper where supplied, rather than running archived absolute-path runners over another experiment. The original private full-study archives preserve remaining exploratory code and all large results. This directory is not represented as a public copy of every checkpoint or every development scratch file.

Compact evidence JSON can have private archive/cloud path fields removed. Such derived compact records must not be presented as byte-identical original receipts. Original hashes and source signatures are retained where scientifically relevant.

The official tool uses a different rendering/word-sampling contract from the exhaustive FreeType comparison. Its native counts are not a defect-classification leaderboard. Read `docs/DIFFENATOR3_COMPARISON_20261024.md` and `docs/RESEARCH_STATUS.md` before drawing conclusions.
